## ② 网站防护

按你说的标准——**「只要不疯狂上传日志，或是全量删除日志，就符合要求」**——做了三件事：

### 1. 没有删除接口（最硬的防护）

整个 Worker **不提供任何删除功能**。要删数据只能你自己在本机用：

```powershell
wrangler d1 execute minexa-crash --remote --command "DELETE FROM crashes WHERE ..."
```

接口不存在，就无从攻击。这比任何"删除前二次验证"都可靠。

### 2. 防疯狂上传（双层限流）

| 层 | 限制 | 作用 |
|---|---|---|
| 每分钟 | 每 IP 20 次 | 挡住脚本狂刷 |
| 每天 | 每 IP 200 次 | 挡住慢慢灌满存储 |

超过就返回 429，数据不落库。

> 说明：限流计数存在 KV 里，KV 是最终一致的，所以这是**软限制**——
> 能挡住脚本，挡不住精心构造的分布式攻击。按你当前的暴露面（一个私密域名、
> 没在任何地方公开过），这个取舍是合适的。

### 3. 查看要登录（密码不再进网址）

**改之前**：`https://.../list?key=密码`——密码会进浏览器历史、Referer 请求头、
也可能被别的网页偷走。

**改之后**：
- 打开 `/list` 会跳到登录页，输一次密码
- 验证通过写一个 **HttpOnly + Secure + SameSite=Lax** 的 Cookie，**30 天免登录**
- Cookie 是 HttpOnly，页面里的 JS 读不到，降低被 XSS 偷走的可能
- 地址栏里永远不出现密码

### 4. 防暴力猜密码

同一 IP 每 10 分钟最多试 10 次，超了返回 429。而且**失败也计数**——
否则可以无限试错直到蒙对。

### 5. 其他

- 页面的崩溃堆栈全部 HTML 转义（XSS 防护）
- 响应带 `X-Frame-Options: DENY`（防点击劫持）、`Referrer-Policy: no-referrer`
- 登录跳转只允许站内路径，防止被构造成钓鱼跳转
- `noindex`，不被搜索引擎收录

### 关于密钥

你选择了**不拆分上报密钥和查看密钥**。说明一下当前状态：

- 上报密钥（`REPORT_KEY`）在 APK 里，反编译能看到，**只能写不能读**
- 查看密码（`VIEW_PASSWORD`）**没有进 APK**，只有你知道
- 我用上报密钥去访问 `/list`，返回 401 —— 已实测

也就是说：即使别人反编译了你的 APK，**也看不到你的崩溃数据**。
这一点比拆分密钥更重要，已经实现了。

### 一个重要修复：出现次数

第一版做出来发现**次数永远是 1**。原因是去重时把重复上报直接丢弃了，
根本没地方存"发生了多少次"。

改成：重复上报时不新增记录，而是 **`occurrences + 1`**、刷新 `last_at`、
用最新堆栈覆盖旧值。这样才能看出「偶发一次」和「每次启动都崩」的区别。

这需要改数据库，所以加了 `migrate-v2.sql`，已经执行过了。

## ④ 合并重复代码

### 实际情况：4 处，不是 3 处

计划书说 3 处，实际是 4 处（漏了第 4991 行 `startBdsViaBox64`）：

| 函数 | 行号（改前） | 用途 |
|---|---|---|
| `runUbuntu` | 1936 | 在容器里跑一次性命令 |
| `startMcInProot` | 4019 | 用 PRoot 启动 Java 版服务端 |
| `startBdsViaBox64` | 4991 | 用 box64 启动基岩版服务端 |
| `probeBdsNetwork` | 5121 | 自检：探容器网络 |

### 做法：不追求"写得一样"，追求"产出一样"

4 处的差异是**真实存在**的：

| 差异点 | runUbuntu | startMcInProot | startBdsViaBox64 | probeBdsNetwork |
|---|---|---|---|---|
| proot 路径 | 字面量 `"proot"` | 绝对路径 | 绝对路径 | 绝对路径 |
| `--kill-on-exit` | 看 tuning | 固定开 | 固定开 | 固定开 |
| `--sysvipc` | 看 tuning | 固定开 | 固定开 | 固定开 |
| 参数写法 | `--rootfs=x` | `-r x` | `-r x` | `-r x` |
| TZ 时区 | 无 | 有 | 有 | 无 |
| DEBIAN_FRONTEND | 有 | 有 | 有 | 无 |
| 额外环境变量 | 无 | 无 | caEnv | 无 |
| 收尾 shell | `/bin/sh -c` | `/bin/sh -lc` | `/bin/sh -lc` | `/bin/sh -lc` |

所以新建了 `ProotCommandBuilder.kt`，把这些差异全部**显式参数化**。
调用方只声明"我这次是什么形态"，具体怎么拼交给它。

以后再加全局参数，**只改这一个文件**。
