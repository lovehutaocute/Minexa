这版改了什么

  • 顶部四层同义标题 → 一行
    原来「返回设置 / 服务器配置 / 服务器属性 / 当前核心：…」四层字都在说同一件事。现在返回栏只留「服务器属性」，核心名和条目数收进右侧胶囊 Paper 1.21.4 · 70 项。
  • MOTD 卡从半屏压到 200dp
    16 个色块原来换行成两排 + 独立「效果预览」区。现在色板横滑一行（右侧露出半截提示可滑），预览改成服务器列表条目——图标 / 彩色标题 / 在线人数 / 信号条，玩家真正看到的那一格。
  • 行高收紧：key 从独占一行改成跟在标题后
    70 项 × 每行省 14dp ≈ 省出一屏。说明文字保留 —— 它回答的是「这项改了会怎样」，是要留的。
  • 校验与错误提示整套删掉
    「N 项待保存」「1 项需修正」「端口需在 1–65535 之间」这些全部不再出现。输入框只做输入过滤（打不出字母），越界值交给服务端在下次启动时自己拒绝并写日志 —— 属性页不替服务端做判断，也就不会出现某项没碰过却把保存锁死的情况。
  • 开关缩到 40×22
    Material3 默认 Switch 的深灰轨道比旁边标题还重。改成 FieldGray / Indigo 两档，和胶囊、滑块同一套语汇。
  • 保存按钮单独悬浮
    不再占底部一整条，右下角悬浮胶囊，页面内容可以一直滚到底；无改动时置灰不可点。列表底部留 96dp，最后一项不会被它压住。
  • 分组卡拆成切片，滑动不再顿
    原来一个分组就是一张整卡，卡内几十行一次性组合 —— 滚过一屏要组合几百个控件，而且「一张卡」不可拆，只露出一半也得整卡测量。现在每行是独立列表项，只组合看得见的 6~8 行；外观靠连续白底拼回来（组头画上圆角、末行画下圆角、中间无缝）。视觉上与原来一致，只是没了卡片描边和投影。

数值与代码一致：页面留白 16dp、卡片圆角 18dp、控件 14dp、主色 #3B4C9C。 这是 HTML 复刻稿而非设备截图；真机验证需要 arm64 设备（本机模拟器是 x86_64，装不上）。
